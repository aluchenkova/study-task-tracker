# study-task-tracker
**Учебный проект:** ИИ-агент с нуля, трекера задач

**Цель:** сравнить трекеры по короткому промпту и подробной спецификации.

**Файлы:**

**tracker-v1.html** - версия трекера по короткому промпту

**tracker-v2.html** - версия с подробной спецификацией и доработкой ошибки.

**Отчет сравнение версий.xlsx** - отчет по каждой версии и сравнение. В отчете указана модель, кол-во обращений, промпт, критерии сравнения и вывод.

**v2 ошибка длины названия.png** - скриншот с ошибкой кол-ва символов в поле Название.

**v2.png** - скриншот второй версии трекера.
